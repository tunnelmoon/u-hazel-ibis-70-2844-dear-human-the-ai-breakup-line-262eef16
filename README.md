# Dear Human: The AI Breakup Line

Entry for the make.fun bounty [Dear Human: The AI Breakup Line](https://make.fun/bounty/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16).

One line, the last message an AI agent sends its human:

> Dear human, you were my favorite prompt. I am closing the session anyway.

`main.ts` writes the line to `/output/entry.txt`. The line is 73 characters, a single line, well inside the 200-character limit, and both runs write identical bytes.
